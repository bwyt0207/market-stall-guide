擺攤副業，是近年台灣上班族最夯的斜槓方式之一。只要週末撥出幾小時，帶著自己的商品走進市集，就有機會在正職之外建立第二份收入。但「擺攤能賺多少？」「要怎麼開始？」仍是許多人卡關的問題。本篇整合實戰數據與新手常見疑問，帶你從零開始規劃擺攤副業。

## 擺攤副業是什麼？為什麼值得考慮？

擺攤副業是指利用週末假日或下班後，在市集、夜市、文創展等場合販售商品，以獲取額外收入的兼職方式。

和其他副業相比，擺攤的優勢在於：

- **啟動成本低**：初期投入可低於 3,000 元（含攤位費與簡易備料）
- **即時回饋**：當天就能知道商品受不受歡迎
- **不需要粉絲基礎**：市集本身提供人流，你只需要學會轉換
- **彈性高**：每個月選幾場擺，完全自由安排

## 擺攤副業能賺多少？實際數字拆解

很多人擔心「擺攤副業划算嗎？」我們用數字說話：

### 收入估算範例（以手作飾品為例）

| 項目 | 數字 |
|------|------|
| 每件商品售價 | NT$200–500 |
| 每場銷售件數（新手） | 10–20 件 |
| 單場營業額 | NT$2,000–10,000 |
| 扣除攤位費（約 NT$500–1,500） | 淨收入 NT$1,500–8,500 |
| 每月出攤場次 | 2–4 場 |
| **每月擺攤副業收入** | **NT$3,000–34,000** |

新手第一場通常偏保守，但隨著陳列、話術、選品越來越熟練，收入成長空間很大。Ryan 的學員中，不乏第三場就開始穩定獲利的案例。

### 影響收入的 3 大關鍵因素

1. **選品是否精準**：對的商品賣給對的市集客群，轉換率差異可達 5 倍
2. **攤位視覺**：吸引人停下來是成交的第一步（參考[攤位陳列技巧](/articles/market-stall-display-tips/)）
3. **現場話術**：好產品還需要好溝通，才能讓路過的人掏錢

## 擺攤副業怎麼開始？5 步驟 SOP

### 步驟 1：找到你的商品定位

**不是「我有什麼就賣什麼」，而是「誰會買、在哪裡買、為什麼跟我買」。**

常見的擺攤副業商品類型：

- **手作類**：香氛蠟燭、手工皂、串珠飾品、皮革小物
- **食品類**：手工餅乾、特色飲品（如水果茶）、自製醬料
- **選品販售**：精選二手書、選物小鋪、復古雜貨
- **技能服務**：人像插畫、名字印章、現場占卜

選品原則：優先選擇**單價 150–600 元之間**的商品，衝動購買門檻低，轉換率較高。

### 步驟 2：規劃成本與定價

擺攤副業新手最容易犯的錯誤，就是定價沒有策略。詳細的定價方法可參考[擺攤定價完全攻略](/articles/market-stall-pricing-guide/)。

**基本成本結構計算：**

```
商品成本 × 3 = 建議售價（含攤位費分攤、雜費）
```

例如：手工皂成本 NT$60，建議售價 NT$180–200。

- **不要因為害怕賣不出去而壓低價格**，低價往往讓顧客覺得品質可疑
- **可設計「組合優惠」**，例如「買 3 個享 9 折」，提高客單價

### 步驟 3：選對市集

不同市集有不同客群，選錯市集是新手最常踩的坑之一。詳細的選市集評估方法請見[怎麼選市集完整指南](/articles/how-to-choose-market-stall/)。

**台灣市集類型與適合商品：**

| 市集類型 | 主要客群 | 適合商品 |
|---------|---------|---------|
| 文創設計市集 | 喜歡獨特風格的年輕人 | 手作、設計感商品 |
| 美食市集 | 親子、饕客 | 食品飲料類 |
| 跳蚤市場 | 尋寶族 | 二手、復古商品 |
| 農夫市集 | 注重天然的消費者 | 有機農產、手工食品 |
| 夜市型市集 | 廣泛大眾 | 高 CP 值商品 |

**選市集的核心邏輯：客群對了，銷售自然事半功倍。**

### 步驟 4：攤位設計與備貨

攤位布置不需要豪華，但要有「視覺引力」。

**基本攤位設備清單（預算 NT$3,000 以內）：**

- 折疊桌（1–2 張）
- 桌布（與商品風格搭配）
- 展示架或層架（增加立體感）
- 價格標示牌
- 防水袋或零錢包（收款用）

完整的設備清單與採購建議，可參考[擺攤設備清單完整版](/articles/market-stall-equipment-checklist/)。

**備貨建議**：新手第一場備貨量不要太多，先以「能賣完 70%」為目標，測試市場反應。

### 步驟 5：設定目標、記錄數據

**「只要勇敢踏出第一步，就能真實感受到市場的回饋與能量。」**

每場出攤前設定具體目標：
- 與至少 20 位顧客主動互動
- 銷售 X 件商品
- 收集 3 個顧客回饋

結束後記錄：銷售件數、熱門商品、顧客反應、天氣/人流狀況。用數據優化，才能讓擺攤副業越做越好。

## 擺攤副業常見問題 FAQ

### Q：擺攤副業需要申請執照嗎？

A：在台灣，若每月銷售額未達 NT$8 萬元（銷售勞務為 NT$4 萬元），通常可暫時免辦營業登記。若銷售規模持續成長，可參考[擺攤許可證申請指南](/articles/market-stall-permit-guide/)了解詳細流程。

### Q：下雨天怎麼辦？

A：部分市集有室內場地，申請時可優先選擇。若在戶外，準備防水帆布是必須的。長期擺攤者也會準備帳篷（約 NT$1,500–3,000），避免日曬雨淋影響商品。

### Q：我沒有什麼才藝，還能擺攤嗎？

A：可以！選品型擺攤（精選二手書、選物店）、代銷型擺攤（販售批發商品加以包裝設計）、甚至是數位類商品（印刷品、手繪圖紙）都不需要特殊技藝，只需要眼光與市場感。

### Q：擺攤副業多久能回本？

A：取決於投入成本與商品類型。一般來說，若攤位費 + 設備費合計 NT$5,000–8,000，通常 2–3 場即可回本。詳細的費用計算請見[擺攤費用完全解析](/articles/2026-05-28_擺攤費用_optimized.md)。

### Q：擺攤副業和正職衝突嗎？

A：大多數台灣市集舉辦在週末，對正職影響極低。部分平日夜間市集可於下班後參加。建議初期每月出攤 1–2 場，逐步增加。

## 擺攤副業新手的 4 大常見錯誤

根據擺攤達人 Ryan 輔導超過 50 位學員的經驗，新手最常犯以下錯誤：

### 錯誤 1：選錯市集
市集人多不代表就是你的客群。賣甜點卻選手工藝品市集，轉換率大打折扣。**選對市集比選對商品更關鍵。**

### 錯誤 2：定價沒策略
太低讓人覺得品質差，太高又沒人買。應根據成本、競品價格、客群消費力三個維度決定定價，而非憑感覺。

### 錯誤 3：以為好產品就能自己賣
市集現場，是銷售能力的競技場。**「好產品只是入場券，成交靠的是現場溝通力。」** 不開口說話、不主動互動，再好的商品都可能沉默收攤。

### 錯誤 4：沒有設定目標
沒有目標，就沒有改善的基準。每場出攤前請設定具體、可衡量的目標，結束後檢視，才能快速進步。
