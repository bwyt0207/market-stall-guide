# 擺攤設備清單完整版：必買、選買、可省，一次搞清楚（附採購攻略 2026）

剛開始研究擺攤，一打開購物網站就頭昏眼花——帳篷要買哪種？桌子要幾張？展示架怎麼搭？刷卡機要不要買？這份**擺攤設備清單**就是為了解決這個問題而生。根據超過 30 場市集實戰經驗，我們將設備分成「必買、選買、可省」三個層次，搭配台灣在地採購地點與實際價格，讓你把預算花在刀口上，第一場就出攤成功。

## 1. 擺攤設備清單：三層次分類法

新手最常犯的錯，就是還沒確認市場反應，就一口氣砸錢買齊所有設備。與其花大錢試錯，不如先搞清楚哪些是「開攤必備」，哪些「之後再說」。

> 「市集擺攤不需要一次做到完美，重點是先去試。你的第一場市集不是要賺大錢，是要學習。設備可以一場一場慢慢補齊。」
> — Ryan，斜槓創業家，30+ 場市集實戰，20+ 場單日銷售破萬

### 第一層：必買設備（Day 1 就要有）

這些是不管賣什麼、在哪個市集擺攤，一定要有的基本配備。沒有這些，攤位根本開不了。

### 第三層：先借 / 二手 / 可省

以下設備雖然好用，但第一場完全可以省下來，或向親友借用、二手購入即可。

- **第二張折疊桌**：先借朋友的，確定會持續出攤再買
- **桌旗 / LOGO 布條**：品牌還沒確定前不必急著做
- **收納箱 / 置物架**：家裡的紙箱先用
- **帳篷帷幕側布**：大多數市集不需要，有需要再補
- **專業刷卡機**：QR Code 收款完全夠用，不需要買設備

## 2. 擺攤帳篷推薦：選購完整攻略

帳篷是所有設備中最貴、也最值得好好研究的投資。選錯了，一整天都不舒服。

### 尺寸怎麼選？3x3 還是 3x6？

**絕大多數市集的標準攤位是 3x3 米**，這也是最主流的帳篷尺寸。除非你確定報名的是大型市集且有申請大攤位，否則優先買 3x3。

| 尺寸 | 適合情境 | 優點 | 缺點 |
|------|---------|------|------|
| 3x3 米 | 一般市集標準攤位 | 輕巧好搬運、停車位放得下 | 空間稍小 |
| 3x6 米（兩組拼接） | 大型市集、雙攤位 | 展示空間大 | 搬運重、費用高 |

**推薦做法**：第一次出攤買 3x3 台製白牌帳篷（[蝦皮](https://shopee.tw/) NT$2,000–$3,500），確定要長期出攤後，再升級品牌款（NT$5,000 以上）。

帳篷腳管粗細也要注意：**30mm 以上的腳管**才夠穩，不會在風大時晃動。

### 台灣夏天、雨天的帳篷注意事項

台灣夏天豔陽高照、雨季來的又急又猛，帳篷選擇要特別留意：

- **防曬係數（UPF）**：夏天出攤必備，選 UPF 50+ 以上的頂布，人在帳篷內才不會被曬爛
- **防水係數（mm）**：頂布防水係數建議 3,000mm 以上，才不會雨天漏水
- **四角配重**：台灣許多市集規定必須掛配重袋（通常每袋 5–10 公斤），沙袋或裝水的水桶都可以替代
- **下雨緊急應對**：備一條大型防水布（塑膠布 NT$100 左右），可以快速覆蓋商品

## 3. 折疊桌椅市集採購指南與展示道具

桌子選對了，商品陳列就成功一半。

### 桌子尺寸與材質選擇

最主流的市集折疊桌有兩種尺寸：

- **120x60 cm**：適合商品不多的新手，好攜帶，一台車就搞定
- **180x75 cm**：陳列面積大，適合商品種類多的攤位，但較重

材質選擇上，**塑膠桌面 + 鐵管腳**是 CP 值最高的組合，蝦皮上 NT$500–$1,200 就能買到堪用品。IKEA 的折疊桌外觀雖然好看，但尺寸未必符合市集需求，建議先比較後再決定。

**小技巧**：買桌子一定要確認「桌腳可調高低」，台灣地面高低不平，可調桌腳是救命功能。

### 攤位展示架推薦（IKEA 洞洞板、增高架）

好的展示能讓商品「立體」起來，吸引更多客人停下腳步：

- **[IKEA SKADIS 洞洞板](https://www.ikea.com/tw/zh/cat/skadis-pegboard-series-37166/)（NT$300–$800）**：搭配各種掛鉤和收納配件，文創攤的熱門選擇
- **折疊展示增高架（NT$300–$600）**：讓後排商品也能被看見，層次感立刻提升
- **S 型掛鉤 + 網片（NT$100–$300）**：帳篷橫管可直接掛商品，充分利用垂直空間

有關攤位佈置的完整技巧，可以參考[市集擺攤完整攻略](https://marketlife101.com/articles/market-stall-guide-complete/)，裡面有更多陳列實戰細節。

## 4. 擺攤行動支付怎麼設定？（新手最容易忘）

台灣消費者越來越習慣用手機付款，市集現場如果只收現金，可能直接流失 30–40% 的訂單。好消息是：設定超簡單，而且不需要花錢買任何設備。

### LINE Pay / 街口 / 台灣 Pay 申請教學

**LINE Pay Money（最推薦）**：

1. 下載 LINE App，進入「LINE Pay」→「收款」功能
2. 申請「個人收款」或「商家收款」（商家版可查看交易記錄）
3. 產生專屬 QR Code，列印或截圖備用
4. 客人掃描 → 輸入金額 → 完成付款
5. 手續費：約 1.5–2%（個人版免費，商家版依方案）

**街口支付**：流程類似，向官網申請收款 QR Code 即可，部分市集族群偏好使用。

**台灣 Pay**：綁定實體銀行帳戶，適合已有商業帳戶的攤主。

### 不需要買刷卡機！

很多新手以為收信用卡一定要買刷卡機，其實不用。台灣市集環境中：

- **QR Code 支付已覆蓋 70% 以上需求**（LINE Pay、街口、全支付）
- 若真的想收信用卡，**iCHEF GO 或 SumUp** 是小型刷卡機的低門檻選擇（設備費 NT$3,000 左右），但第一場完全不需要

**強烈建議**：第一場先只準備 LINE Pay QR Code 立牌 + 足夠零錢，確認市集客群後再決定要不要升級收款設備。

## 5. 食品攤 vs 文創攤設備清單比較

兩種攤位類型的核心需求差異很大，以下是詳細對比：

| 設備項目 | 食品攤 | 文創手作攤 |
|---------|-------|----------|
| 帳篷 | 必備（遮陽防雨） | 必備 |
| 折疊桌 | 1–2 張（備料＋販售分開） | 1 張（展示用） |
| 展示增高架 | 不需要 | 強烈建議 |
| 洞洞板 | 不需要 | 推薦 |
| 保溫箱 / 保冷袋 | 必備 | 不需要 |
| 瓦斯爐 / 電磁爐 | 現做攤位必備 | 不需要 |
| 食品容器 / 餐盒 | 必備 | 不需要 |
| 食品衛生手套 | 必備 | 不需要 |
| 標價牌 / 菜單板 | 菜單式大看板 | 小標價牌即可 |
| 照明設備 | 視情況 | 重要（商品細節需要打光） |
| 消毒酒精 / 濕紙巾 | 必備 | 備用即可 |
| 零錢備用金 | NT$3,000–$5,000 | NT$1,000–$2,000 |
| 行動支付 | 必備 | 必備 |

**食品攤特別提醒**：台灣市集對食品攤有衛生規範，出攤前務必確認主辦方規定（部分需要食品業者登錄），且食材的備貨量估算非常關鍵，避免過多浪費。

**文創攤特別提醒**：展示「視覺層次」決定你的吸客力，一定要善用增高架和洞洞板，把商品從「堆在桌上」變成「精心陳列」。

## 常見問題 FAQ

**Q1：第一次擺攤設備最少要花多少錢？**

基本版（帳篷 + 桌椅 + 手推車 + 配重）約 NT$4,000–$8,000。如果帳篷向朋友借，費用可以壓低到 NT$1,500–$2,000 以內。重點是先試、先出攤，不要等設備「齊全了」才行動。

**Q2：帳篷要買 3x3 還是 3x6？**

新手一律先買 3x3。這是台灣市集最通用的標準尺寸，超過 90% 的攤位都是用這個規格。確認要長期出攤、且有大型市集需求後，再考慮升級。

**Q3：折疊桌要買哪種？**

120x60 cm 的 CP 值最高，適合大多數新手。挑選重點：桌腳可調高低、承重 50 公斤以上、含把手方便搬運。蝦皮上 NT$700–$1,000 的評價款式通常就夠用。

**Q4：擺攤行動支付怎麼設定？需要買刷卡機嗎？**

不需要買刷卡機。申請 LINE Pay 個人或商家收款，列印 QR Code 立牌，就完成了。整個流程 10 分鐘內搞定，完全免費。

**Q5：擺攤設備要去哪裡買最便宜？**

| 設備 | 最便宜管道 |
|------|----------|
| 帳篷 | [蝦皮](https://shopee.tw/)（台製白牌） |
| 折疊桌椅 | 全聯 / 家樂福季節特賣 |
| 展示道具 | [IKEA SKADIS 系列](https://www.ikea.com/tw/zh/cat/skadis-pegboard-series-37166/)、蝦皮 |
| 手推車 | 全聯、家樂福、蝦皮 |
| 配重袋 | 買帳篷時一起買（通常有優惠組合） |

**Q6：食品攤和文創攤的設備需求有什麼不同？**

最大差異在於：食品攤需要保溫 / 保冷設備、烹調器具和衛生用品；文創攤則更需要展示道具（洞洞板、增高架）和打光設備。兩者都需要行動支付和基本桌椅，但展示邏輯完全不同。詳見本文第 5 節的比較表。

**Q7：戶外擺攤下雨怎麼辦？**

- **事前**：確認帳篷頂布防水係數（建議 3,000mm 以上）
- **備料**：帶一條大型塑膠防水布（NT$100 左右），雨突然來時快速覆蓋商品
- **攤位設計**：避免把所有商品貼近帳篷邊緣擺放，留出 30cm 安全距離
- **心態**：雨天市集流量低，但留下來的客人購買意願較高，保持好服務就好

**Q8：第一場出攤最容易忘記帶哪些東西？**

根據實戰經驗，最常遺漏的是：行動電源（手機沒電就無法收款）、零錢（沒有零錢找不開，失去成交機會）、防水備品（突然下雨時商品全濕）。建議出發前照本文 Checklist 逐一核對，可大幅降低遺漏機率。

**Q9：市集擺攤帳篷要哪裡買才有保固？**

帳篷推薦直接在[蝦皮](https://shopee.tw/)購買有品牌、有評價的台製帳篷，多數賣家提供 3–6 個月保固並可聯繫維修。避免選路邊夜市攤位購入，出問題後無法追蹤售後服務。
