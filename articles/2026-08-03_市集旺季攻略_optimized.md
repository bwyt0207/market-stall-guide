# 市集旺季攻略完整指南：中秋、聖誕、春節如何讓單日業績翻倍？

對市集攤販來說，**市集旺季攻略**是每年最重要的課題之一。台灣一年有幾個超級黃金檔期——中秋前後、聖誕跨年、農曆春節——在這些時間點，市集人流可能是平日的 3–5 倍，同樣的攤位、同樣的商品，業績卻可能差距懸殊。關鍵就在「你有沒有做好旺季準備」。本篇帶你全面規劃市集旺季策略，讓每次旺季都能讓業績真正翻倍。

---

## 台灣市集旺季年曆

了解旺季分布，才能提前規劃。以下是台灣市集攤販必須掌握的年度旺季：

| 旺季 | 時間區間 | 特點 |
|------|----------|------|
| 中秋節 | 9月中下旬（農曆8月15日前後2週） | 家庭聚會、送禮需求高 |
| 萬聖節 | 10月最後兩週 | 文創、手作市集特別旺 |
| 聖誕節/跨年 | 12月第3週至1月1日 | 全年最長旺季，送禮+狂歡雙需求 |
| 農曆春節 | 農曆年前1個月至初五 | 送禮、年節氣氛、消費力高峰 |
| 母親節 | 5月第二個週日前後2週 | 手作、保養、食品特別暢銷 |
| 情人節 | 2月14日前後 | 手工禮品、甜食、飾品需求大增 |

**策略重點：** 旺季前 6–8 週就要開始備貨和行銷規劃，而非等到旺季才開始準備。

## 旺季攻略 5 大準備要素

### 準備 1：提前 6–8 週規劃商品線

旺季最常見的錯誤是「備貨不足」或「備貨錯方向」。

**商品規劃 3 步驟：**

**第 1 步：回顧去年同期數據**  
如果這是你第一年，觀察同類型攤位的旺季商品（IG、市集現場、競品分析）。如果有去年紀錄，直接看哪些商品在旺季動最快、哪些滯銷。

**第 2 步：設計「節日限定款」**  
旺季顧客的購買動機是「這個時節的特別感」。普通商品加上節日包裝、限定款式，就能讓購買理由更充分：
- 中秋：月餅口味、月亮意象的包裝
- 聖誕：紅綠白色系、雪花/星星元素
- 春節：紅色系、金色、吉祥話設計

**第 3 步：計算備貨量**  
旺季備貨量 = 平時每場銷量 × 旺季倍數係數（建議 2–3 倍）  
寧願多備 20% 後來特賣清倉，也不要因備貨不足讓旺季提前收攤。

擺攤達人 Ryan 的實戰心得：「旺季前我會特別製作聖誕限定口味的水果茶，提前 2 週在 IG 預告，結果開攤前就已經有顧客排隊等著買限定款。」

### 準備 2：爭取黃金攤位

旺季人潮多，但不是每個攤位都能平等受惠。攤位位置在旺季的重要性被放大 3 倍。

**選攤位的原則：**
- **入口動線**：顧客一進場就看得到，轉換率最高
- **主通道兩側**：主要人流必然經過
- **美食區周邊**：吃飽的顧客更願意逛攤、花錢

**提前申請策略：**
- 多數知名市集的旺季攤位會提前 2–3 個月開放申請
- 關注市集官方 IG / FB，開放申請通常會提前公告
- 建立與市集主辦方的關係——認識主辦，旺季時更容易拿到好位置
- 備案 2–3 個市集，旺季不是每個市集都能申請到位置

**小技巧：** 如果無法選到最好的位置，用「高度」彌補位置劣勢。高攤位（立架、高展示台）在人多時能被更遠的顧客看到。更多攤位選擇技巧請見：[擺攤完整攻略](https://bwyt0207.github.io/market-stall-guide/)

### 準備 3：旺季行銷提前佈局

旺季前 4–6 週開始行銷，效果遠勝於旺季當週才開始宣傳。

**行銷時間軸（以聖誕旺季為例）：**

| 時間 | 行銷動作 |
|------|----------|
| 11月初（D-60） | IG 開始發「聖誕季預告」，建立期待感 |
| 11月中（D-45） | 公布限定款設計、接受預購 |
| 11月底（D-30） | 公告出攤日期和場地，LINE 推播通知 |
| 12月初（D-20） | 倒數發文、顧客互動（留言抽獎等） |
| 12月中（D-7） | 最後一波預告，強調「限量/限定」 |
| 出攤當天 | 現場直播/限時動態，吸引可以當天趕來的顧客 |

**有效的旺季行銷文案公式：**  
「限定 + 稀缺感 + 節日情感 + 具體利益」  
例：「🎄只有聖誕季才有！手工焦糖蘋果水果茶，每場限量 30 瓶，喝完就沒了。12/20 在 XX 市集等你。」

### 準備 4：人力與流程配置

旺季人流激增，單人作業往往接不住。

**人力規劃：**
- **2 人攤位基本配置**：1 人接待、說明商品；1 人收款、包裝
- 找可信賴的朋友/家人協助，或考慮付費邀請幫手（時薪 NT$180–250）
- 提前訓練助手熟悉：商品介紹、收款流程、常見問題回答

**流程優化：**
- **預先包裝**：暢銷商品提前打包，旺季現場直接拿取，縮短等待時間
- **定價清楚標示**：減少詢問價格的時間損耗
- **收款 QR Code 大牌顯眼**：讓顧客不用等你空出手，自己掃碼轉帳
- **找零準備充足**：旺季現金多，備好大量找零零錢（建議準備 NT$5,000 以上的小鈔）

---

### 準備 5：旺季後的追蹤與收尾

很多攤販把旺季當「賺完就算」，錯過最重要的數據累積機會。

**旺季結束後 3 天內要做的事：**

1. **記錄銷售數據**
   - 哪些商品最暢銷（前3名）
   - 哪些商品滯銷（後3名）
   - 單日最高來客時段
   - 客單價平均

2. **整理新顧客名單**
   - 加了多少 LINE 好友
   - IG 新增多少追蹤
   - 有幾個顧客留下聯絡方式

3. **顧客滿意度回饋**  
   旺季後 1 週，在 IG/LINE 發感謝文，附帶「你最喜歡什麼商品？」的互動問題，收集真實反饋為下次備貨參考。

4. **存貨盤點**  
   哪些材料還有庫存？剩餘品清倉或轉作日常款？

## 旺季預算規劃參考

| 項目 | 平時費用 | 旺季費用 | 增幅原因 |
|------|----------|----------|----------|
| 備貨成本 | NT$3,000–5,000 | NT$8,000–15,000 | 量多 + 限定包裝材料 |
| 攤位費 | NT$800–2,000 | NT$1,500–4,000 | 旺季場地費通常較高 |
| 行銷素材 | NT$0–500 | NT$500–1,500 | 額外設計、印刷 |
| 人力費用 | NT$0 | NT$1,500–3,000 | 助手費用 |
| **總計** | **NT$4,000–8,000** | **NT$11,500–23,500** | |

**旺季目標業績：** 建議設定旺季場次的業績目標為平時的 2.5–3 倍，才能覆蓋增加的成本並維持合理利潤。

## 旺季最常犯的 5 個錯誤

**錯誤 1：備貨太晚**  
很多供應商在旺季前 2 週就缺貨，提前備貨才能確保拿到最好的原料。

**錯誤 2：所有商品全換成節日款**  
保留 30–40% 的常態款，避免不喜歡節日風格的顧客無法購買。

**錯誤 3：低估人流，一人撐攤**  
旺季一個人根本應付不了，放棄「省人力費用」的想法，旺季的多賺遠超過人力成本。

**錯誤 4：忘記追蹤旺季帶來的新顧客**  
旺季顧客可能在平時也喜歡逛市集，只要維持聯繫就是長期顧客，不追蹤等於白白浪費。

**錯誤 5：旺季結束不做覆盤**  
沒有覆盤，下一年就要重新摸索。10 分鐘的覆盤記錄，能讓明年旺季少走半年彎路。

## 常見問題（FAQ）

**Q：第一次參加旺季市集，備貨多少最安全？**  
A：建議先參加一場旺季市集觀察人流，備貨量抓平時的 1.5 倍。觀察後再調整下一場的備貨量，避免第一次備太多造成資金壓力。

**Q：旺季市集的攤位費比較貴，值得申請嗎？**  
A：以聖誕/春節等旺季而言，人流量是平時的 3–5 倍，就算攤位費貴一倍，投資報酬率通常仍遠高於平時。值得申請，但要確認市集品質和人流承諾。

**Q：沒有節日限定款，旺季可以參加嗎？**  
A：可以，但建議至少調整包裝（節日包裝紙、節日提袋），或在定價上設計一個「旺季優惠組合」，讓顧客感受到節日的特別感。

**Q：旺季要如何避免貨賣完卻還有很多顧客的情況？**  
A：預購制度是解法——旺季前在 LINE/IG 開放預購，確認訂單後才備貨，降低剩貨風險。同時也能提前掌握需求量。
