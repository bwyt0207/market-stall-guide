# 怎麼選市集？新手擺攤必看的市集選擇完全指南

剛開始擺攤，很多新手的第一反應是「找人最多的市集」，結果商品全天幾乎沒賣出去，才發現：人潮多，不代表你的客人在那裡。**怎麼選市集，才是擺攤成功最關鍵的第一步。** 本篇文章完整拆解台灣市集類型、選市集前的評估方法、以及如何識別風險市集，新手讀完就能避開最常見的坑。

## 為什麼選對市集比努力更重要？

擺攤達人 Ryan 在 30 場以上的市集實戰中，歸納出新手最常犯的第一個錯誤就是：**選錯市集**。

他的親身觀察：「賣手工甜點去二手收藏市集，一整天就算賣了 20 件，轉換率還是不到 2%。同樣的商品換到文創手作市集，第一個小時就賣出超過一半庫存。」

選市集的邏輯很簡單：

> **你的商品要出現在「對的人」面前，而不只是「最多人」面前。**

## 選市集前必做的 3 步驟評估

### Step 1：確認自己的品牌定位與客群輪廓

在選市集前先回答三個問題：
- 我的商品賣給誰？（年齡、性別、興趣）
- 我的商品定價在哪個區間？
- 我的品牌風格是文青、質感、親和、還是個性？

品牌定位和市集調性不符，就算人再多也是白搭。

### Step 2：蒐集市集完整資訊

報名前必須確認：
- 市集主題與參攤商品限制（有些市集不接受食品攤）
- 攤位費用結構（含押金、押金退款條件）
- 攤位尺寸與提供設備（桌椅、電源、雨天棚架）
- 宣傳管道與預估人流
- 雨天因應方案（延期 / 取消 / 不退費）

### Step 3：評估主辦單位可信度

這是很多新手跳過的步驟，也是最容易踩雷的地方。

查詢方式：
- Google 搜尋主辦單位名稱 + 「評價」、「心得」
- 在 Facebook 市集社團（如「Twmarket 台灣文創手作市集快報」）搜尋主辦名稱
- 查看主辦單位的粉絲頁成立日期、過往活動照片數量、攤商回饋

## 選市集的 6 大現場核查重點

人流「對不對」遠比「多不多」重要，但以下幾個現場條件同樣影響你當天的業績：

**① 攤位選位方式**  
主辦是否提供選位？還是隨機分配？靠近入口、主走道的攤位業績可以差到 3 倍以上。好的主辦會讓攤商提早確認位置。

**② 卸貨與停車便利性**  
你的設備可能重達 50 公斤。卸貨距離超過 200 公尺就是一場體力消耗戰，影響你開攤前的狀態。

**③ 是否提供桌椅與電源**  
部分市集需要自備，要提前算入租借費或設備重量。

**④ 雨天取消與退費政策**  
務必白紙黑字確認。「雨天順延」和「雨天不退費」對你的財務規劃影響很大。

**⑤ 攤商類別管制**  
好的主辦會控制同類攤位數量，避免飾品攤旁邊全是飾品攤。報名時可以詢問同類商品的攤數限制。

**⑥ 主走道動線設計**  
現場路線是否清楚？入口明顯？動線單向還是雙向？人流動線直接影響每個攤位的曝光率。

## 新手入門選市集的最佳路徑

**建議路線：小型 / 校園市集 → 社區市集 → 中型文創市集 → 大型知名市集**

原因：
- 小型市集攤位費低（NT$500-800），試錯成本低
- 可以測試陳列、話術、定價，找到最佳組合
- 累積攤商口碑和照片後，報名大型市集更有說服力

> Ryan 建議：新手前 3 場不要急著去大型市集，寧可在小市集把陳列和銷售流程跑順，再進大場。多擺幾個不同類型的市集，才能找到自己商品真正的客群甜蜜點。

## 這些市集紅旗要當心（識別風險市集）

近年台灣市集詐騙案頻傳，攤商應注意以下高風險警示：

### 高風險紅旗清單

| 紅旗 | 說明 |
|------|------|
| 無公司行號或統編可查 | 合法主辦通常有可查詢的商業登記 |
| 粉絲頁剛成立（不到 6 個月）| 無歷史活動紀錄，可信度低 |
| 收費方式只能匯款到個人帳戶 | 無法申請退款，風險極高 |
| 押金 + 攤位費超過 NT$3,000 | 市集費用通常 NT$500-2,000，超標需警惕 |
| 主辦不公開電話、只用 LINE 聯絡 | 出事後難以追蹤 |
| 只在 FB 私人社團招商，無公開頁面 | 訊息傳播受限，不透明 |
| 在市集社團中完全沒有人認識此主辦 | 詢問老攤商是最快速的查核方法 |

### 真實案例警示

- **台南端午深夜市集**：招募 50 攤，當日只到場 7 攤，主辦人員神隱，攤商氣憤如遭詐騙
- **高雄新春市集鬧雙胞**：同一攤位被售予至少 4 組攤商，被害人超過 20 名
- **全台市集婚宴押金詐騙**：有人在市集現場偽稱婚宴採購商，以「訂製大量商品須付押金」為由詐騙，全台至少 22 名攤商受害、損失逾 200 萬

**自保原則：報名前先在 Facebook 市集社群搜尋主辦名稱，並詢問認識的老攤商是否有過往合作記錄。**

## 常見問題（FAQ）

**Q：文創市集和一般假日市集，新手選哪個比較好？**  
A：如果你賣的是手作或設計類商品，優先選文創市集。雖然審核較嚴，但客群消費力更高，也更容易累積品牌忠誠度。如果商品是食品類，假日親子市集是更好的起點。

**Q：攤位費多少才算合理？**  
A：台灣一般市集攤位費 NT$800-2,000/天屬於正常範圍。超過 NT$3,000 需評估市集的人流品質；低於 NT$500 要確認主辦是否有能力辦好活動。

**Q：同一場市集，攤位位置差異影響有多大？**  
A：靠近入口、主走道交叉點的攤位業績可達末端攤位的 2-3 倍。報名時可主動詢問能否選位，或表明希望靠近特定區域。

**Q：怎麼從外部照片判斷市集人流品質？**  
A：看主辦過往活動照片的背景，確認是否有大量一般消費者（非只有攤商）。看攤商臉書評論是否有提到「業績」、「人氣」等正面回饋。

**Q：被詐騙了怎麼辦？**  
A：第一步先保留所有匯款紀錄、對話截圖；向 165 反詐騙專線或當地警察局報案；並在市集社群公開提醒，避免更多攤商受害。
