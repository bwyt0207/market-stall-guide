# 擺攤怎麼記帳？完整收支管理指南：從成本計算到損益分析

很多人擺了三個月的市集，卻不知道自己到底有沒有賺錢——這是攤主最常見的盲點之一。

問題不是賣得不夠好，而是**沒有建立記帳習慣**。擺攤怎麼記帳，是每個認真做副業的攤主必學的核心技能。不記帳，就算每天收錢都有感覺，但進貨成本、攤位費、交通費東扣西扣之後，利潤可能比你想的少很多。

## 為什麼擺攤一定要記帳？

擺攤達人 Ryan 帶過超過 50 位學員，他觀察到一個共同問題：**新手攤主普遍只看「收入」，忘記「成本」。**

常見的自我欺騙情境：
- 當天收了 NT$6,000，覺得賺很多
- 但忘了計入：進貨成本 NT$2,500 + 攤位費 NT$800 + 交通費 NT$300 + 包材費 NT$200
- 實際淨利：NT$2,200——不到預期的一半

記帳的目的不是為了麻煩自己，而是**讓你做出正確的經營決策**：

1. 知道哪些商品真的有利潤
2. 判斷某個市集值不值得繼續去
3. 累積數據，為下一次出攤做準備

## 擺攤成本的 5 大分類

在開始記帳之前，先搞清楚你的成本有哪些。

### 1. 進貨 / 製作成本（變動成本）
- 原料費（手工品、食材等）
- 外包加工費
- 損耗費（食材腐損、瑕疵品）

**食品攤位特別注意：** 生鮮食材的損耗率約 15–30%，定價時要把這部分算進去，否則帳面上看起來有賺，實際上可能是虧損。

### 2. 攤位費（固定成本）
- 市集攤位費（通常一次 NT$300–2,000，依市集規模）
- 電費加收（部分室內市集另收電費）

### 3. 交通費（變動成本）
- 油錢 / 停車費
- 計程車、叫車費
- 大眾運輸費用

### 4. 設備折舊（長期成本）
- 帳篷、桌椅、展示架
- 建議按使用次數攤提：設備總價 ÷ 預計使用次數

例：帳篷 NT$3,000，預計使用 60 次 → 每次折舊成本 NT$50

### 5. 包材 / 雜費（變動成本）
- 包裝袋、紙盒、標籤
- 印刷品（名片、菜單）
- 零錢備用金消耗
- 名牌、手機架、行動電源等耗材

## 推薦記帳工具

### 工具一：Google 試算表（免費，推薦新手）

- 建一份「出攤記帳表」，每次出攤後填入
- 可設公式自動計算利潤率、累計收入
- 手機、電腦都能同步查看
- 適合手動輸入、細項管理

**建議欄位：** 日期、市集名稱、天氣、總收入、各項成本、淨利、備註

### 工具二：記帳 App（推薦日常快速記錄）

- **Ahorro**（免費）：可自訂分類、有月度圖表
- **CWMoney（錢錢日記）**：台灣開發，支援中文分類
- **Money Manager**：收支一目了然，有統計功能

適合在現場用手機快速輸入每筆銷售，回家後再統整到 Excel。

### 工具三：紙本現金簿（現金為主的攤位）

如果你的攤位以現金交易為主，紙本記帳最不容易出錯：
- 每筆收款當場記錄金額
- 一天結算一次
- 月底抄到 Excel 做分析

## 月底盤點：這 3 個數字最重要

每月底做一次整理，重點看這三個數字：

### 1. 每場淨利
某個市集平均每次淨利多少？低於 NT$800–1,000 的市集，可能不值得繼續報名。

### 2. 各商品貢獻利潤
哪個商品賣最多？哪個商品利潤率最高？未必是最暢銷的商品利潤最好。建議建立「商品利潤表」，記錄每個 SKU 的售價、成本、毛利率。

### 3. 成本佔比
- 理想狀況：進貨成本佔總收入的 30–40%，總成本不超過 60%，利潤率至少 40%
- 如果成本佔比超過 70%，代表定價策略需要調整

## 常見問題 FAQ

**Q：擺攤需要開發票或報稅嗎？**
A：台灣規定，年營業額超過 NT$48 萬（每月 NT$4 萬）才需要辦理稅籍登記。大多數兼職攤主在此門檻以下，不需要開發票。但若攤位是主要收入來源，建議諮詢會計師確認。

**Q：食品攤位有哪些法規成本要注意？**
A：販售食品需辦理「食品業者登錄」，若使用瓦斯等設備建議投保公共意外責任險（年保費約 NT$3,000–8,000），這些都要計入固定成本。

**Q：設備折舊怎麼計算比較合理？**
A：最簡單的方式是「使用次數攤提法」：設備總價除以預計使用次數，每次出攤計入固定折舊金額。例如帳篷 NT$4,000 預計用 80 次，每次折舊 NT$50。

**Q：進貨損耗怎麼入帳？**
A：建議在每次出攤後記錄「實際售出數量」vs「進貨數量」，差額即為損耗。月底統計損耗率，並在定價時預留損耗空間。食品類建議損耗預留 15–20%。

**Q：行動支付的收款記帳怎麼做？**
A：LINE Pay、街口等行動支付平台都有交易記錄可以下載，建議每週匯出一次對帳，與現金收入合併計算總收入。

## 擺攤記帳的 3 個常見錯誤

### 錯誤 1：只記大項，忘了小費用
交通費、停車費、網路費、名片印刷費——這些「小費用」個別看起來微不足道，但累計下來每月可能佔利潤的 10–20%。

### 錯誤 2：沒有區分市集的表現
如果同時在多個市集出攤，卻把收入和成本混在一起，就無法判斷哪個市集划算、哪個市集該放棄。建議每個市集單獨記帳，每季做比較。

### 錯誤 3：忽略時間成本
記帳要考量時間成本：前置作業（備貨、包裝、搬運）+ 出攤時間 + 收攤整理。如果出攤 8 小時淨利 NT$600，換算時薪只有 NT$75，可能不划算。

## 擺攤記帳實戰範例

**範例：手工飾品攤，週日假日市集**

| 項目 | 金額 |
|------|------|
| 當日銷售收入 | NT$4,800 |
| 材料成本 | NT$1,440（30%）|
| 攤位費 | NT$600 |
| 交通費 | NT$300 |
| 包材費 | NT$120 |
| 設備折舊（攤提）| NT$80 |
| 總成本 | NT$2,540（53%）|
| **淨利** | **NT$2,260（47%）** |

→ 這個市集利潤率 47%，表現不錯，值得繼續。
