# 第一次擺攤需要準備什麼？新手 0 元啟動完整指南

**第一次擺攤需要準備什麼**，是許多有副業夢想的人最常問的問題。很多人以為「要準備好一切才能出攤」，其實不然——借桌椅、手機收款，最低幾百元就能跨出第一步。這篇文章完整整理出攤準備 SOP、擺攤設備清單、市集選擇、收款設定與擺攤陳列技巧，讓你第一次擺攤就有方向。

## 一、出攤前：先設定你的第一次目標（不是衝業績）

很多市集新手帶著「第一次就要大賺」的心情出攤，結果賣不好就大受打擊，然後就放棄了。

這是最常見也最可惜的錯誤。

**第一次擺攤的真正目標，不是業績，而是「學習驗證」。**

建議用以下 3 個 KPI 取代「賺多少錢」：

| 學習 KPI | 具體衡量方式 |
|----------|-------------|
| **產品吸引力** | 有幾個路人停下來看？問了哪些問題？ |
| **定價合理性** | 路人的反應是「太貴」還是馬上買單？ |
| **陳列效果** | 哪個角度吸引最多人？照片有沒有比現場好看？ |

**副業 ROI 思維：** 第一次擺攤的「投資報酬」不是金錢，而是資訊。你花一天市集費換來的顧客反饋，比你在家想破頭三個月還有價值。

**如果第一次沒賣出去怎麼辦？**

這完全正常，而且比你想像中更普遍。沒賣出去代表：
- 定價需要調整
- 陳列方式需要改變
- 或者這個市集不是你的目標客群

沒賣出去不是失敗，是免費的市場調查。帶著觀察回家，下次就會更好。

## 二、必備擺攤設備清單與最低採購預算

市集新手最常問的就是「要買什麼設備？」以下分兩階段整理，讓你根據預算選擇適合的出攤準備方案。

**0 元啟動組合（最低門檻）：**

| 項目 | 取得方式 | 費用 |
|------|---------|------|
| 折疊桌椅 | 向親友借 | $0 |
| 手機 + 行動電源 | 自己已有 | $0 |
| 帆布袋 / 托特包陳列 | 家中現有 | $0 |
| 手寫價格牌 | 紙板自製 | $0 |
| 零錢備用金 | 先準備 $500-1,000 | $500–1,000 |

**進階新手標配（預算 $2,000–5,000）：**

| 項目 | 建議選擇 | 預算 |
|------|---------|------|
| 折疊桌（180cm） | 網購或 B&Q | $800–1,500 |
| 折疊椅 | 輕量露營椅款 | $300–600 |
| 帆布遮陽傘 | 視市集是否提供 | $0–1,500 |
| 小推車 / 行李車 | 搬運商品必備 | $500–1,000 |
| 價格標籤 + 展示架 | 文具店購買 | $200–500 |
| 擺攤零錢準備 | 100 元、50 元、10 元各備 | $500–1,000 |

> **新手建議：** 第一次先借或用現有物品，確認自己真的喜歡擺攤後再投資設備，避免衝動採購後束之高閣。

## 三、攤位申請與市集選擇：新手最適合哪種市集？

市集種類很多，新手選錯市集容易踢鐵板。以下是常見類型與適合程度：

| 市集類型 | 特色 | 新手適合度 |
|---------|------|-----------|
| **社區假日市集** | 人流穩定、費用低（$500–1,500/天） | ★★★★★ 最適合 |
| **手作市集（室內）** | 客群精準、氣候不影響 | ★★★★☆ 適合 |
| **文創市集** | 品牌形象好、競爭較激烈 | ★★★☆☆ 中等 |
| **百貨商場快閃** | 人流大、費用高（$3,000+） | ★★☆☆☆ 不建議新手 |
| **網紅打卡市集** | 申請競爭激烈、費用高 | ★☆☆☆☆ 不建議新手 |

**手作市集報名管道推薦：**
- Facebook 社團：「台北市集」「手作市集徵攤友」等關鍵字搜尋
- Instagram：追蹤各市集帳號，留意徵攤公告
- Accupass 活動平台：搜尋「市集 攤位」
- 各縣市文化局官網：有補助型文創市集資訊

**報名注意事項：**
- 確認市集主辦方有無提供桌椅（可大幅降低搬運負擔）
- 確認攤位尺寸（通常 90cm × 180cm 或 180cm × 180cm）
- 確認有無電源插座需求
- 確認天候取消政策（戶外市集雨天如何處理）

> 更多市集資訊與攤位申請資源，可參考 [市集擺攤資源總整理](https://brianw108.github.io/market-stall-guide/resources/)

## 四、現場設置 SOP：從搬運到開攤的時間規劃

做好出攤準備不只是帶對東西，時間規劃同樣關鍵。以下是完整的當天 SOP 讓你不手忙腳亂。

**前一天準備清單：**
- [ ] 商品盤點並分類裝箱（按陳列順序）
- [ ] 擺攤零錢準備好（建議 $500–1,000，含各幣值）
- [ ] 行動電源充滿電
- [ ] 收款 QR Code 列印備用（防手機沒電）
- [ ] 確認隔天天氣，備好帽子、防曬或雨具

**當天時間規劃（以開攤 10:00 為例）：**

| 時間 | 任務 |
|------|------|
| 08:00 | 出發，提早抵達確認攤位位置 |
| 08:30 | 搬運商品、架設桌椅 |
| 09:00 | 陳列商品、擺設價格牌 |
| 09:30 | 拍攝攤位照片、發 IG/FB 打卡 |
| 09:45 | 最後確認收款方式、備用零錢位置 |
| 10:00 | 準時開攤 |

## 五、收款設定：現金 + 行動支付一次搞定

數位收款是現代擺攤必備，很多路人身上沒帶現金，沒有提供行動支付就等於少了一批潛在買家。

**推薦新手設定的行動支付：**

### Line Pay 申請步驟（個人商家）
1. 下載 Line App → 點選「錢包」→「Line Pay」
2. 申請「一卡通 MONEY」帳戶並完成實名認證
3. 至 [Line Pay for Business](https://pay.line.me/tw/) 申請商家帳號
4. 審核通過後取得收款 QR Code（約 3–5 個工作天）
5. 列印 QR Code 或顯示於手機供顧客掃描

### 街口支付申請步驟
1. 下載「街口支付」App
2. 點選「我要收款」→「商家申請」
3. 填入基本資料（個人身分證或統編）
4. 審核通過後可立即使用收款 QR Code（約 1–3 天）

**收款工具比較：**

| 工具 | 申請難度 | 收款手續費 | 推薦指數 |
|------|---------|-----------|---------|
| Line Pay | 低 | 約 1.5–2% | ★★★★★ |
| 街口支付 | 低 | 約 1.5% | ★★★★☆ |
| 現金 | 無需申請 | 0% | 必備 |

> **重要：** 行動支付申請需要幾天審核，**請在出攤前 1–2 週就開始申請**，避免當天才發現還沒開通。

## 六、攤位陳列 3 個關鍵：讓路人停下來

好的攤位佈置能讓路人自動放慢腳步，差的擺攤陳列技巧讓人走過去都沒注意到你。

### 關鍵 1：高低層次感

平鋪一片的陳列最無聊。用書架、展示台、木箱創造高低差，讓視覺有焦點。

**低成本方案：** 把木頭箱子倒扣墊高、用書放在桌布下製造高度、用透明壓克力展示架。

### 關鍵 2：清楚的價格標示

路人最怕「不好意思問價錢」，沒有價格牌等於趕客。

- 每件商品都要有價格
- 用醒目字體，字要夠大（站在 1 公尺外能看到）
- 可加上「3 件 $XXX」等組合優惠誘導購買

### 關鍵 3：主力商品前置

你最想賣的、最有特色的商品，放在攤位正前方視線高度。路人只有 3 秒決定要不要停下來，讓你的「招牌商品」先說話。

**攤位佈置加分技巧：**
- 加入品牌感元素（自製小 logo、名片、包裝袋）
- 自然光或補光燈讓商品更好看
- 保持桌面整潔，賣完的商品位置立刻補上

## 七、常見問題 FAQ

**Q1：第一次擺攤要帶多少零錢？**

建議備 $500–1,000 的零錢，包含：100 元硬幣 × 5、50 元 × 10、10 元 × 20。大多數台灣市集商品定價在 100–500 元之間，這個備用金能應付大部分找零需求。

**Q2：擺攤需要申請執照嗎？**

一般手作市集或假日市集以「短期活動」型態運作，不需要另外申請執照。但若長期固定於同一地點銷售，建議諮詢地方政府規定。以手作市集為主的新手通常無需額外申請。

**Q3：商品沒賣完怎麼辦？**

這是每個擺攤人都會遇到的正常情況。解決方案：
- 帶回家重新拍照後上網路平台販售（Pinkoi、蝦皮、Instagram）
- 下次市集繼續帶出
- 拆解後重新製作成其他商品

**Q4：天氣不好還要出攤嗎？**

視市集主辦方規定而定。戶外市集通常有雨天取消或延期機制，出攤前確認清楚取消政策。若是室內市集則不受影響。個人建議：輕微陰天可以出攤，大雨天氣不建議，商品容易受潮且人流極少。

**Q5：第一次擺攤需要帶名片嗎？**

強烈建議！即使只是簡單印上 Instagram 帳號或 Line ID，讓對你商品有興趣但當天沒購買的路人可以找到你。這是免費累積潛在客戶最有效的方式之一。
